Elles servent à dire au navigateur : "Prépare-toi, on va bientôt avoir besoin de parler à ces serveurs, ne perds pas de temps !"
Sans ces lignes, le navigateur attend de voir une image ou un appel API dans ton code JavaScript pour commencer à s'en occuper. 
Avec ces lignes, il gagne une étape cruciale.
